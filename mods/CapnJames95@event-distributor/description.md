# Event Distributions

Browse supported event Pokemon and eggs with filters, previews and a claim journal. Includes Emerald Aurora, Mystic and Eon Ticket journeys with supported original event provenance. English Emerald native Old Sea Map/Mew unlock is intentionally excluded.

Supports Emerald, FireRed and LeafGreen. Recommend gen1recomp 0.3.42+. Import the individual ZIP, enable the mod and restart. Other collection mods, including Dual Screen, are optional.

[Instructions and screenshots](https://github.com/CapnJames95/gen1recomp-mod-releases/blob/main/mods/event-distributor/README.md)

Developed with AI assistance using OpenAI Codex. Automated checks and some manual testing have been performed; full gameplay and unrelated-mod compatibility are not certified. Back up saves.
