# QoL Suite

One download with individual switches and original options. Includes Pokemon Services, Fly Teleport, Day Care Viewer, Quick Heal Party, Capture Assistant, Summary IVs, Scrollable Start Menu, Quiet EXP, Quick Field Actions, Sorted Bag, Battle Ball Shortcut, Battle Bar Speed, Held Berry Replacement, Dex Companion, Faster Center Healing, HM Field Kit with Sweet Scent, Hold Fast Forward, Fast Text, Key Item Help, Town Map Companion, Party Held Items, Party Nickname, Party Move Reminder, Quicker Save Confirmation, Repel Reuse, Reusable TMs, Running From Start, Shop Owned Count, Expanded Summary and VS Seeker/Match Call readiness. Disable L/R Help is FR/LG-only. Hoenn Tools is Emerald-only and adds rematches, berries/patch teleports, Frontier records, Feebas assistance, contests/Pokeblocks, bike swapping, daily events and Secret Bases.

Disable old standalone QoL copies and restart. START > QOL > QOL SETTINGS: A toggles each feature, SELECT opens options, Left/Right changes pages, B returns.

Supports Emerald, FireRed and LeafGreen. Recommend gen1recomp 0.3.42+. Import the individual ZIP, enable the mod and restart. Other collection mods, including Dual Screen, are optional.
